# Employee Profile Generator

A beginner-friendly Python mini project that generates employee profile information using variables, string concatenation, f-strings, type conversion, and string slicing.

## Project Structure

```text
Employee-Profile-Generator/
│
├── profile_generator.py
└── README.md
```

## Features
- Generate employee full name using first and last names.
- Create and format employee address.
- Display employee age and experience.
- Generate an employee information card.
- Display employee position and salary.
- Extract department code from employee ID.
- Extract joining year and employee initials.
- Extract the last three digits of employee code.

## Python Concepts Used
- Variables
- String Concatenation
- F-Strings
- Type Conversion (`str()`)
- String Slicing
- Positive Indexing
- Negative Indexing
- String Formatting
- `print()` Function

Created as a beginner Python practice project to improve understanding of variables, string operations, formatting, and data extraction using Python.
