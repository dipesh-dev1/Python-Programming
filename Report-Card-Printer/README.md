# Report Card Printer

A beginner-friendly Python project that demonstrates student information and basic Python data types using variables, `type()`, and `isinstance()`.

## Project Structure

```text
Report-Card-Printer/
│
├── report_card_printer.py
└── README.md
```

## Features
- Store student name using a string variable.
- Store student status using a Boolean variable.
- Store student age using an integer variable.
- Store student score using a float variable.
- Display the data type of each variable.
- Check data types using `isinstance()`.

## Python Concepts Used
- Variables
- Data Types
- String (`str`)
- Integer (`int`)
- Float (`float`)
- Boolean (`bool`)
- `type()` Function
- `isinstance()` Function
- `print()` Function

## How to Run

```bash
python report_card_printer.py
```

## Purpose

Created as a beginner Python practice project to understand variables, data types, and type-checking functions in Python.
