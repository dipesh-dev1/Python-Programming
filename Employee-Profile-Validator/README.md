# Employee Profile Validator

A beginner-friendly Python mini project that cleans, formats, and validates employee information using Python string methods.

## Project Structure

```text
Employee-Profile-Validator/
│
├── profile_validator.py
└── README.md
```

## Features
- Extract username from an email address.
- Check the presence of @ symbol and .com extension.
- Clean employee names by removing extra spaces.
- Convert names into uppercase and lowercase.
- Remove dashes from phone numbers.
- Split and join address information.
- Check employee code prefixes.
- Count dots and dashes in strings.

## Python Concepts Used
- Variables and Data Types
- F-Strings
- String Methods
- String Slicing
- String Searching
- String Formatting
- String Manipulation

## How to Run

```bash
python profile_validator.py
```

## Purpose

Created as a beginner Python practice project to improve my understanding of string manipulation, data cleaning, and basic validation.
