## Getting started

### Prerequisites

- [Python 3.8 or newer](https://www.python.org/downloads/)
- Git (optional, for cloning)

### Clone the repository

```bash
git clone https://github.com/dipesh-dev1/Python-Programming.git
cd Python-Programming
```

### Run a script

```bash
python age.py
```

On some systems the command is `python3` instead of `python`.

Scripts that use command-line arguments (such as `argparse1.py`) can be run with `-h` to see the available options:

```bash
python argparse1.py -h
```
